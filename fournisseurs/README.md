# Fournisseurs

Critères : **stock en UE**, livraison ≤ 3 jours idéalement (9 jours max), opérateur responsable UE (GPSR), suivi de colis, échantillons possibles.

## Pistes à étudier
| Fournisseur | Type | Atout | À vérifier |
|---|---|---|---|
| CJ Dropshipping | Agent / catalogue | Entrepôts en Europe (dont France/Allemagne), compatible Shopify, gratuit | Stock UE disponible pour le produit précis, délais réels |
| BigBuy | Grossiste UE (Espagne) | Stock en UE, factures UE | Catalogue limité aux produits « classiques » |
| AutoDS | Outil d'automatisation | Import produits, suivi prix/stock, fournisseurs avec entrepôts US/UE | Coût de l'abonnement, fournisseurs UE pour le produit |
| Fournisseurs AliExpress avec entrepôt « FR » / « ES » | Marketplace | Prix bas | Fiabilité, conformité CE/GPSR |
| Achat de petit stock + envoi depuis la France | Stock propre | Livraison 24-48 h, contrôle qualité | Avance de trésorerie, à faire seulement sur un produit validé |
