# Fournisseurs

> **Modèle : dropshipping pur.** Pas de stock acheté : le fournisseur reçoit chaque commande et expédie directement au client. « Stock UE » = stock du fournisseur dans un entrepôt européen. Les pistes « stock propre » ou « prix de gros pour X pièces » des anciens documents sont écartées.

Critères : **stock en UE**, livraison ≤ 3 jours idéalement (9 jours max), opérateur responsable UE (GPSR), suivi de colis, échantillons possibles.
