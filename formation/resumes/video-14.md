# Vidéo 14 — NOTES INTERMÉDIAIRES (en cours de lecture)

Auteur : Louis, « professeur Shopify depuis 2 ans » ; feuille de route / mind map gratuite en description ; appel de coaching proposé. Boutique de démo « Elite Drink » (électrolytes en poudre, variantes de goût pastèque, pomme-banane…).

## Lu 0–80 000
- Ch.2 Forfait : offre 3 j gratuits puis 3 mois à 1 €/mois (au lieu de 27–39 €/mois) ; forfait Basique pour 90–99 % ; Grow si besoin de comptes employés ; Advanced = frais 1,5 → 1,1 % ; Plus > ~500 k€ CA/an. Offre 20 $ de crédit si domaine ajouté. Crédit de 1 % des ventes en abonnement (offre temporaire, jusqu'au 12/07/2026, plafond 4 500 $). Paiement annuel = > 100 €/an économisés.
- Ch.3 Compte : email dédié, adresse pro ; « ignorer la configuration personnalisée ».
- Ch.4 Charte : couleur principale, couleur d'accent (boutons), couleur de fond = accent à 3–5 % d'opacité (ex. #FFFEF8) ; 2 polices (titre avec personnalité ; texte sans empattement) ; logo + pastille via Canva (gratuit) ; dossier d'images.
- Ch.5 Images ChatGPT : prompts dans feuille de route ; partir d'une photo fournisseur/concurrent (« pour s'inspirer, pas voler ») ; étapes : 1) packaging pro avec nom de marque, 2) variantes ensemble, 3) une image par variante (même conversation = cohérence), 4) gros plan 3–4 sachets, 5) produit + fruits + gouttes d'eau, 6) bannière (tous produits dans cuisine lumineuse), 7) images d'ambiance à partir d'images de style. Règle : fiche produit = 1 produit par image ; accueil/collection = plusieurs produits. Cohérence de style = valeur perçue. Demander les images une par une.
- Ch.6 Paramètres :
  - Détails boutique : nom marque, email admin ≠ email contact, téléphone (appli OnOff pour numéro virtuel), adresse facturation ; format devise « € » sans « EUR » ; région France, métrique, kg, fuseau Paris.
  - Traitement commandes : NE PAS exiger étape de confirmation (−20–30 % conv. selon lui) ; ne rien traiter automatiquement au début ; archivage auto OK.
  - Marque : logo carré, couleurs, image de couverture (partage réseaux), slogan, description courte, liens réseaux sociaux.
  - Utilisateurs : Basique = 1 seul ; ne JAMAIS partager ses identifiants (passer Grow 1 mois si besoin).
  - Paiement (checkout) : contact par email ; décocher suivi via Shop (peu utilisé en Europe) ; ne jamais exiger connexion compte ; exiger prénom+nom ; nom d'entreprise : ne pas inclure ; adresse ligne 2 et téléphone facultatifs ; consentement marketing email/SMS : cases NON précochées (RGPD) ; pourboires : non (flou juridique UE) ; langue FR ; adresse facturation différente autorisée ; validation d'adresse activée.
  - Comptes clients : par défaut ; activer retours en libre-service ; crédit magasin OK.
  - Expédition : renommer « Express 10,99 € » en « Livraison VIP – assurance perte/casse/vol » (5–15 % la prennent, pertes ~1–2 % → marge ; rembourser toujours les colis perdus) + livraison standard gratuite (ou gratuite dès 65 €) ; rester sur la France au début ; ajouter Belgique/Suisse via Markets si besoin ; étiquettes Shopify Shipping : Colissimo, Mondial Relay, Chronopost ; dates de livraison estimées en manuel (délai de traitement + acheminement) ; points relais gratuits (↑ conversion) ; livraison locale / retrait magasin si pertinent ; emballage par défaut.
  - Taxes : activer services fiscaux auto ; voir expert-comptable.
  - Applications : désinstaller Shopify Messaging (remplacé par une autre app email) ; canaux de vente : garder Boutique en ligne, désinstaller Shop et Point de vente.
  - Domaine : acheter via Shopify, prendre le .com (et .fr si budget) ; activer renouvellement auto.

## Lu 80 000–160 000
- Domaine (suite) : vérifier les infos du titulaire (sinon suspension), propagation 24–48 h ; redirection email (contact@domaine → boîte perso) ; hébergement email pro possible ; ne jamais promouvoir l'URL myshopify.
- Événements clients (pixels) : plus tard. Notifications clients : logo + couleur d'accent dans les emails ; vérifier l'email expéditeur (idéalement email au domaine). Langue : français par défaut.
- Ch.7 Cookies / confidentialité : politique de confidentialité automatisée Shopify ; bannière cookies automatisée, couleurs personnalisées, position bas-centre ; afficher la bannière au checkout = conforme RGPD mais baisse conversion (il le recommande quand même) ; journal des consentements ; page d'opposition au partage automatisée ; activer Shopify Network Intelligence ; données hébergées UE ; case marketing jamais précochée hors US.
- Ch.8 Mentions légales : modèles Shopify (retours/remboursement, conditions de service, coordonnées) à insérer puis publier ; politique d'expédition + mentions légales via prompt ChatGPT de la feuille de route (questions : forme juridique, nom, domiciliation, SIREN, TVA non assujetti, email, domaine, RCS, hébergeur Shopify Inc., directeur de publication, pays d'expédition, transporteurs Colissimo/Mondial Relay — « Colis Privé » souvent en dropshipping —, délai préparation 24 h, livraison ex. 6 j ouvrés, frais, suivi, procédure litige). CGV ≈ conditions de service.
  - Règles de retour : retours en libre-service ; délai légal min. 14 j UE, il recommande 30 j ; retour gratuit (argument de conversion), pas de frais de restockage.
  - Entreprise obligatoire avant la 1re vente (sinon blocage Shopify Payments) ; micro-entreprise dans la plupart des cas ; SASU si gros projet/propres produits/déduire les charges.
  - Promo LegalPlace (lien affilié, code « LouisShopi » −25 %) : pack Express 24 h 99 € (assistance juridique, aide ACRE) ; domiciliation 17 €/mois (payée à l'année, 60 rue François 1er Paris) — arguments : adresse perso masquée (boutique, Facebook, TikTok), CFE « la moins chère de France à Paris » (à vérifier), courrier scanné, pas de transfert de siège en cas de déménagement ; compte pro Qonto optionnel. Alternative gratuite : guichet unique INPI.
  - ACRE : < 26 ans, demandeurs d'emploi, handicap… ; charges micro ≈ 12 % du CA (vente) ; rien à payer sans CA.
- Ch.9 Shopify Payments : entreprise individuelle ; dénomination = nom-prénom ; SIRET 14 chiffres (Kbis/extrait, ~1–2 semaines via LegalPlace) ; n° TVA intracom même si non assujetti ; adresse pro = domiciliation ; catégorie d'activité précise (Retail…) ; téléphone sur relevé bancaire ; NIF personnel ; adresse résidentielle (non affichée) ; documents : Kbis/preuve d'immatriculation, justificatif de domicile, pièce d'identité ; frais annoncés 1,5 % + 0,25 € ; PayPal intégré à Shopify Payments ; ajouter compte de versement + 2FA ; désactiver Shop Pay ; garder CB/Visa/MC/Amex, Apple Pay, PayPal ; Klarna possible (paiement en plusieurs fois) ; crypto optionnel ; fréquence des versements ; libellé relevé = nom de marque court ; mode test ; capture automatique des paiements (jamais manuelle) ; Mollie possible mais non recommandé. Shopify Plus = 2 300 $/mois.
- Ch.10 Ajouter produits : titre (ex. « Électrolyte – mangue ananas ») ; images cohérentes (la 1re est la plus importante) ; description courte en puces (3 bénéfices) ; IA Shopify possible ; catégorie produit précise ; prix 9,90 € avec prix barré 14,90 € ; ne pas facturer la TVA en micro ; coût unitaire (3 €) → marge affichée (69 %) ; stock suivi (sync auto DSers/AutoDS en dropshipping) ; SKU/code-barres facultatifs ; « continuer à vendre en rupture » seulement si réassort rapide ; emballage (dimensions, poids) ; variantes (option « Format » : 20/40/100 sachets ; prix 9,90/19,90/49,90 ; stock par variante ; image par variante) ; aperçu moteurs de recherche (titre + méta-description SEO).

## Lu 160 000–280 000
- Produits (suite) : modification groupée (prix, stock, descriptions) pour gagner du temps.
- Ch.11 Collections : supprimer la collection par défaut ; titre + description très courte (ne pas repousser les produits) ; image de collection (plusieurs produits) ; ajout manuel des produits ; SEO (titre « Collection – Marque », méta-description) ; créer une collection « Meilleures ventes » (produits de collections différentes) pour l'accueil.
- Ch.12 Menus (Contenu > Menus) : menu principal = Accueil (indispensable, beaucoup ignorent que le logo ramène à l'accueil) + collection vedette + « Nos produits » (sous-menus = autres collections, glisser à droite pour imbriquer) + À propos + Contact ; menu « Nos collections » (footer) ; menu « À propos » (Accueil, Rechercher, À propos, Contact) ; créer la page « À propos » dans Boutique en ligne > Pages.
- Ch.13 Thème : éviter les thèmes externes (Envato, ThemeForest, thèmes d'influenceurs) — non validés par Shopify, peuvent casser lors d'une mise à jour pendant qu'on dépense en pub ; 1 036 thèmes dont 24 gratuits ; les gratuits récents (Horizon → Fabrique : Tinker, Atelier, Savor, Heritage, Peach…) = MÊME thème « à blocs » sous des habillages différents ; les anciens (Dawn → Trade, Origin, Refresh, Sense…) = même thème « à sections », plus limité. Payants (≈ 380 $ une fois, par des agences) : Impulse (très utilisé), Impact (petits catalogues 10–20 produits) ; « si 380 $ vous paraît cher, ce n'est pas pour vous maintenant ». Générateur de thème IA Shopify : joli mais pas optimisé conversion. Choix démo : Tinker (gratuit), publier puis supprimer Horizon.
- Préférences : mot de passe (désactiver à l'ouverture) ; image de partage réseaux ; titre + méta-description de l'accueil.
- Ch.15 Paramètres du thème : logo + favicon (pastille) ; couleurs via « nuanciers » (schémas) : fond, textes TOUJOURS noirs sur fond clair, bouton principal = couleur d'accent (orange) avec survol, bouton secondaire = contour ; 2e nuancier fond jaune ; typo texte Poppins, titres « Calama » en gras ; animations par défaut ; badges promo avec nuancier d'accent ; rayons de bordure IDENTIQUES partout (cohérence) ; panier en TIROIR, ouverture auto à l'ajout, note au vendeur seulement si utile, réductions dans le panier oui, boutons de paiement accéléré oui, lien « continuer les achats » ; cartes produit : ajout rapide au survol (pas sur mobile), 2e image au survol OUI, carrousel ; recherche vide → collection meilleures ventes ; pastilles de variantes activées ; pas de CSS perso.
- Ch.16 Header : barre d'annonce (fond couleur d'accent, jamais la couleur des boutons), 2 annonces en rotation 5 s, TOUJOURS un lien (ex. « Livraison gratuite » ; « Découvrez nos électrolytes » → collection), emojis seulement si la DA le permet (pas en premium) ; logo à gauche, menu au centre sur la même ligne ; pas de compte client ; icône recherche seulement si beaucoup de produits ; retirer sélecteurs pays/langue si un seul marché ; en-tête fixe « au défilement vers le haut » ; pas de bordure ; transparence de l'en-tête sur l'accueil seulement (pas sur fiches produit/collections) ; méga-menu avec produits ou collections en vedette, images au format carré partout ; mobile : barre de navigation horizontale recommandée.
- Ch.17 Footer : badges de réassurance + 2 menus + logo + réseaux sociaux ; supprimer le bloc newsletter (« plus personne ne s'inscrit », sauf lead magnet type ebook) ; même nuancier et espacements que la barre d'annonce (« encadrer » la page) ; menu « Nos collections » + menu « À propos » (accordéon mobile facultatif) ; logo en image arrondie (~16–19 % largeur) ; « Suivez-nous sur les réseaux sociaux » ; bandeau politiques (liens auto) sans séparateur gris ; retirer « Propulsé par Shopify » ; réassurance via section « Icône avec texte » : Livraison rapide (expédition 24–48 h), Paiement sécurisé, Retours 30 jours (option écologie), regroupés dans un groupe horizontal avec bordure couleur d'accent.
- Ch.18 Accueil (5 sections) : bannière principale → collection vedette → « Qui êtes-vous ? » (média + texte) → liste de toutes les collections → mission/vision → footer. Bannière : image multi-produits, pas de lien sur toute la section, mise en page verticale, hauteur « grand », texte blanc lisible + superposition sombre (« une page d'accueil optimisée est une page qu'on peut lire »), pas de dégradé si header transparent, pas d'effet flou.

## Lu 280 000–400 000
- Accueil (suite) : bannière avec bouton d'appel à l'action principal (couleur d'accent, vers la collection phare) + titre « Découvrez nos… » + 3 arguments différenciants (goût naturel, recette française…) ; « travailler le copywriting : ce qui vous différencie ». Collection vedette = meilleures ventes, grille de 3–4 produits (jamais 2 ou 5), carrousel si > 4, 2 colonnes sur mobile, format d'image carré, pas de bordure ; 2e image au survol du même style. « Qui sommes-nous » (média + texte) : fond d'accent, image IA, ≤ 3 lignes, bouton SECONDAIRE (« Découvrir la marque » → page À propos). Liste de collections en « bento » (titres en pastille couleur bouton = cliquable). Mission/vision en multicolonne (facultatif) ou bandeau défilant. Footer éventuellement en noir avec texte blanc.
- Ch.19 Page collection : groupe titre + description de la collection (dynamiques, ne pas toucher aux sources) + image arrondie ; grille (jamais « éditorial »), cartes moyennes, petites cartes sur mobile si > 4 produits ; images carrées ; ajouter une liste « bento » des autres collections (« Découvrir toutes les collections » — corriger la mauvaise traduction « Magasiner par collection »).
- Ch.20 Fiche produit (Tinker) : média à gauche ; barre d'ajout au panier flottante (sticky) OUI ; galerie : grille avec 1re image pleine largeur sur ordinateur, vignettes arrondies ou « indice » (aperçu de l'image suivante) sur mobile, jamais points/compteur ; images carrées ; zoom activé ; colonne d'infos fixe sur ordinateur ; ordre : titre (titre 3 si trop gros), étoiles d'avis (app Trustoo, ex-« Trust »), prix (retirer la mention taxes), description courte en puces remontée sous le prix, sélecteur de variantes en boutons (pastilles couleur), bloc « stock du produit » (seuil de stock bas), quantité + ajout panier, retirer éventuellement le paiement accéléré, icônes de paiement sous le bouton, mini-réassurance (camion « Livraison gratuite en 48 h », paiement sécurisé, retours) — idéalement sous le prix ; accordéons « Description » alimentés par un CHAMP MÉTA produit (texte multiligne, ex. ingrédients/origine/conservation) via « source dynamique » pour un contenu différent par produit ; icônes de réassurance produit = arguments PRODUIT uniquement (ne pas mélanger avec livraison/paiement) ; supprimer la vidéo par défaut ; section « Comment ça marche » (multicolonne 3 étapes avec images IA) ; FAQ (accordéons, largeur max « aucun », réduire l'espacement) ; collection vedette « Découvrir la collection… » ; bento des autres collections. « Ne pas tout mettre à droite comme dans les formations de gens qui n'y connaissent rien ».
- Ch.21 Page contact : texte (horaires, délai de réponse) + formulaire (bouton « Envoyer » en couleur forte) + image (carte de la ville) avec téléphone, email, adresse.
- Ch.22 Checkout (Paramètres > Paiement > Personnaliser) : logo ; option bannière pleine largeur avec image de réassurance faite sur Canva (avis, note, SAV rapide, retours gratuits) sinon logo dans le résumé ; couleurs de fond = charte ; accent et boutons = couleur des boutons.
