# Formation : vidéos d'e-commerçants

## Comment m'envoyer une vidéo
Je ne peux pas regarder les vidéos. Pour chacune, envoie (au maximum 5 à 10 vidéos par message, sinon la session plante) :
1. Le **lien** et le **titre**.
2. La **transcription** : sur YouTube, « … » sous la vidéo → *Afficher la transcription* → tout sélectionner → copier-coller.

Chaque vidéo est résumée dans `resumes/` (un fichier par vidéo). La synthèse globale et la méthode retenue sont dans `synthese.md`.
